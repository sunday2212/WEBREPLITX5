Steps to Get ChatGPT / OpenAI API Key

Follow this guide to create an OpenAI developer key for AI Quiz, Quiz Battle, and the medical doubt solver.

ChatGPT / OpenAI Platform

OpenAI API keys are created on the OpenAI developer platform. A ChatGPT subscription and API billing are separate, so check the API platform account before using the key.

Model used by this app: GPT-5.6

Step 1: Open the OpenAI API keys page

Open the official OpenAI API keys page in a new tab.

OpenAI PlatformUse the official platform.openai.com domain and sign in to the account you want to use.

Step 2: Check API billing

OpenAI API access is billed separately from ChatGPT Plus. If the platform asks for billing or credits, complete that step before making API requests.

API billing is separateChatGPT Plus does not automatically provide OpenAI API credits.

Step 3: Create a secret key

Click Create new secret key, give it a recognizable name such as AI Quiz, and confirm the dialog.

Create new secret keyUse a separate key for this app so it is easy to revoke later if needed.

Step 4: Copy the key immediately

Copy the secret key while it is displayed. It normally starts with sk-. OpenAI does not show the full secret key again after the dialog is closed.

Copy and protect itNever share the complete key in a screenshot, chat, or public repository.

Step 5: Save it in the app

Return to AI Quiz Setup, Quiz Battle, Profile, or the doubt solver. Select ChatGPT (OpenAI), paste the key, and press Save API Key. It will be reused everywhere.

One key, all AI featuresAfter saving, the other supported screens automatically use this saved OpenAI key.
Keep your key private

If the key is exposed, delete it from the OpenAI platform and create a replacement. Monitor usage and set limits in the provider dashboard.
