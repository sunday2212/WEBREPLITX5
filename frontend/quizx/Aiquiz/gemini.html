Steps to Get Google Gemini AI API Key

Follow this guide to create a Google AI Studio key for AI Quiz, Quiz Battle, and the medical doubt solver.

Google Gemini / AI Studio

Gemini API keys are created in Google AI Studio. The app uses your selected provider key across all AI features, so you only need to enter it once.

Model used by this app: Gemini 3.5 Flash Lite

Step 1: Open Google AI Studio

Open the official Google AI Studio API keys page in a new tab.

Google AI StudioUse the official Google domain and check that you are signed in to the account you want to use.

Step 2: Sign in with Google

Sign in with your Google account. If you have not used AI Studio before, accept the terms shown on the screen and continue to the workspace.

Sign in or create an accountA Google account is required to create and manage your AI Studio keys.

Step 3: Create an API key

Click Create API key. Select an existing Google Cloud project if prompted, or create a new project for this app.

Create API keyChoose a project, then confirm the key creation request.

Step 4: Copy the key

Copy the generated key immediately and keep it private. Do not put it in a public post, screenshot, or source repository.

Copy and protect itGoogle may not display the complete secret in the same way again after you leave the page.

Step 5: Save it in the app

Return to AI Quiz Setup, Quiz Battle, Profile, or the doubt solver. Select Google Gemini, paste the key, and press Save API Key. It will be reused everywhere.

One key, all AI featuresAfter saving, the other supported screens automatically use this saved Gemini key.
Keep your key private

If you think the key was exposed, delete it in Google AI Studio and create a replacement. Free limits and availability are controlled by Google and can change.
