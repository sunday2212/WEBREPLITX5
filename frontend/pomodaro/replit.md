# Pomodoro Timer

## Overview
A simple Pomodoro technique timer web application built with vanilla HTML, CSS, and JavaScript.

## Features
- Digital clock display showing current time
- Countdown timer with configurable hours, minutes, and seconds
- Break time settings for Pomodoro technique cycles
- Sound alerts when timer and break end
- Sound toggle and mute controls

## Project Structure
- `index.html` - Main HTML page
- `clock.js` - JavaScript for clock and timer functionality
- `clockx.css` - Styling for the application

## Running the Application
The app is served using Python's built-in HTTP server on port 5000.

## Deployment
Configured as a static site deployment.
